NISHA BIRTHDAY WEBSITE — CAKE CUTTING VERSION

Upload these files to the ROOT of your GitHub Pages repository:
- index.html
- style.css
- script.js
- photos/ (keep all four nisha-*.webp images inside)

This version has no love/matching game. After the four photo memories, the visitor reaches a small 3D animated birthday cake and taps “Cut the cake ♡”. The cake animates, candles go out, and the birthday wish opens.

Replace the existing index.html, style.css and script.js in GitHub. Keep the existing photos folder if it already contains all four images.
Music starts only after the visitor taps the Music button because browsers block autoplay.
