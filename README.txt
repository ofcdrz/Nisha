ROMANTIC PROPOSAL WEBSITE

Files:
- index.html: page structure
- style.css: design and animations
- script.js: YES/NO interactions, hearts and optional synthesized chime
- proposal-bg.png: generated background artwork

Preview: open index.html in a browser.
GitHub Pages: create a GitHub repository, upload all files in this folder to the repository root, then go to Settings > Pages > Deploy from a branch > main > /(root) > Save. Wait for the published URL to appear in Settings > Pages.

To personalize, edit the text in index.html. Keep all files together.
